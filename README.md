# Sleepfi WordPress Theme (オリジナル WordPress テーマ)

## Overview
このリポジトリは、静的 HTML/CSS/JS サイトを WordPress テーマ化したプロジェクトです。  
更新・運用を前提として、テンプレート構成や管理画面の使いやすさを意識したテーマ設計を行いました。

## Purpose
本テーマの制作を通じて、以下の点を学び・実装しています。

- WordPress テンプレート階層の理解と活用
- 投稿・固定ページ・カスタム投稿の使い分け
- 実務運用を意識したテーマ構成と編集画面の設計

## Features
- ニュース（通常投稿）表示機能
- GOODS（カスタム投稿）管理機能
- 管理画面の編集 UX を改善するための UI 設計
- 更新・修正を前提とした CSS・構造設計
- jukebox プレイヤー連動を含むインタラクション実装

## Technology
- WordPress
- PHP
- HTML / CSS / JavaScript



## Custom Post Type (Goods)
カスタム投稿タイプとして「Goods」を実装し、  
音源 URL・アーティスト名・価格などの項目を入力できる管理画面を用意しています。  
編集画面では、運用者にとってわかりやすい UI となるよう構成しました。

## Administrative UX Improvements
- 管理画面の表示項目を整理し、必要な情報だけを入力できるよう最適化
- メディアアップロード・音源選択機能の追加により更新作業を簡便化
- 閲覧・修正が容易な投稿構造で、運用を意識した設計

## How to Use
1. WordPress 環境にテーマを配置 (`wp-content/themes/`)
2. テーマを有効化
3. 投稿・Goods カスタム投稿からコンテンツを追加
4. 管理画面から各種情報を更新

## Development Environment
- Local development (XAMPP / MAMP など)
